Cached.jl

Cached.jl provides cmap and pcmap — drop-in replacements for Base.map and Distributed.pmap that transparently cache results. On the first call each input is hashed and the result stored in the chosen backend; on any subsequent call the cached value is returned immediately without re-running the function.

Quick start

using Cached

# Pick a backend — results persist across Julia sessions
cache = SQLiteCache("results.sqlite")

# First call: every element is computed and stored
results = cmap(x -> x^2, cache, 1:100)

# Second call: everything is already cached, no computation
results = cmap(x -> x^2, cache, 1:100)

Cache backends

TypePersists?Best for
DictCacheNoDeduplication within a single run
FileCacheYes (files)Large objects, any serializable value
SQLiteCacheYes (SQLite)Many small/medium items, concurrent access

Parallel mapping

using Cached, Distributed
addprocs(4)

cache = SQLiteCache("results.sqlite")
results = pcmap(x -> expensive_fn(x), cache, 1:1000)

Caching a single function

wrap_cache adds caching to one function at a time, for cases where cmap/pcmap don't fit:

cache = SQLiteCache("results.sqlite")
expensive_fn_cached = wrap_cache(expensive_fn, cache)

expensive_fn_cached(x)  # computed and cached
expensive_fn_cached(x)  # returned from cache
